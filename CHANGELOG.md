# Changelog

## 0.1.0

- Initial release.
- Syntax highlighting for NNEF graph files (`.nnef`), covering the flat and compositional syntax of NNEF 1.0.5.
- Syntax highlighting for NNEF quantization files (`graph.quant`, `.quant`).
- Language configuration: comments, brackets, auto-closing pairs, indentation and folding.
- Snippets for common NNEF constructs.
